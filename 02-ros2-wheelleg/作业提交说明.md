| 项目 | 结果 | 数据来源 |
|---|---|---|

速度斜坡限制内部目标变化率，不是对实际轮子/机体的同值硬加速度限幅。抗扰结果只对应本次轻微人工操作：推力大小、方向及撤力时刻未同步测量，不能宣称量化的牛顿数承受能力。此前更大或重复扰动存在失败记录，不宣称通用稳定保证。

目前前进越障目标为 0.625 m/s，不能替代“0.3 m/s 前进 3 m”的加分专项验收。手柄跳过，转向跟随未完成。JSON 中 motion_bonus_validated=false 与该范围一致。

## 运行

使用已有教程环境及原始依赖 rm_msgs、wheel_leg_sim、机器人模型。在 `02-ros2-wheelleg/Tutorial/ros2_ws` 加载 rm_ros2 和 ROS2 Jazzy 环境后：

```bash
colcon build --symlink-install --packages-up-to wheel_leg_controller
source install/setup.bash
bash run_obstacle_demo.sh
```

单独运行附加验证：

```bash
bash run_acceleration_test.sh
bash run_disturbance_test.sh
```

每次只运行一组试验，从新仿真开始。辅助脚本采用已有仿真参数 realtime=true、rtf=1.0，未改变仿真器、模型或控制步长。控制器不调用 MuJoCo API。试验结束后数据已保存时，部分运行出现 GLFW 图形窗口退出断言，该退出问题尚未修复。
